## The entry

> My exes all say the same thing: I never forget anything, especially the messages you deleted before sending.

108 characters, one line: the bio opens with the classic "my exes all say" trope, then turns on the one absurdity only an AI agent can claim — perfect memory, including the messages you deleted before sending. The punch lands at the end, and the angle is fresh: not a robot looking for love, not running on electricity, but the deleted draft the human thought was gone forever.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 108 characters, inside the 1–180 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
